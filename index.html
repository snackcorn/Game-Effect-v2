📋 처음 연결하기

기록은 시작한 날의 연도별 탭(예: 2026)에 자동 저장됩니다. 종료일이 비어 있는 행은 시작일 하루에만 달력 블록으로 표시됩니다. 첫 번째 줄에는 항목 이름을 적습니다. 최소한 아래 두 칸은 꼭 필요합니다.

시트 작성이 어렵다면 CSV로 저장 또는 Excel로 저장을 눌러 기본 틀 파일을 먼저 받은 뒤, Excel 또는 Google Sheets에서 열어 사용하세요.

저장 파일 차이
  • CSV: 가볍고 단순한 한 장짜리 파일입니다. 다른 서비스에 기록을 옮길 때 편합니다.
  • Excel: 시작일 연도별 탭이 나뉜 .xlsx 파일입니다. Excel에서 계속 정리할 때 편합니다.
A1이름필수
B1시작일필수

권장 전체 헤더: 이름 | 시작일 | 종료일 | 플랫폼 | 시간 | 엔딩여부 | 메모 | 한줄평 | Steam AppID | Steam 누적시간

로컬 기록과 시트 기록이 다를 때 기록 가져오기를 누르면, 시트 데이터를 사용할지 현재 로컬 기록을 유지할지 확인합니다.

주의: 기록 추가·수정·삭제·Steam 제목 변환은 현재 브라우저의 전체 기록을 연도별 시트에 다시 저장합니다. 처음 연결할 때는 반드시 먼저 기록 가져오기로 시트 기록을 불러오고, 중요한 시트는 사본을 만들어 두세요.

처음 Steam까지 함께 연결할 때: 시트 주소·저장 주소·SteamID64를 입력한 뒤 처음 데이터 통합 동기화를 누르세요. 시트를 먼저 불러오고 Steam AppID를 연결한 뒤 최신 플레이 정보를 반영합니다. 연결되지 않은 기존 Steam 기록이 있으면 중복 방지를 위해 멈춥니다.

스프레드시트 입력 예시

1행은 항목 이름을 입력하는 첫 줄입니다. 노란색 칸은 꼭 필요합니다.

연결 코드 넣는 방법

  1. 스프레드시트에서 확장 프로그램 → Apps Script를 엽니다.
  2. 기존 코드를 지우고 아래 코드를 붙여 넣은 뒤 저장합니다. 전체 코드 복사 버튼을 사용할 수 있습니다.
  3. 처음이면 배포 → 새 배포 → 웹 앱, 기존 웹 앱을 고치는 경우 배포 → 배포 관리 → 수정 → 새 버전으로 배포합니다.
  4. 실행 계정은 나, 액세스 권한은 모든 사용자로 설정합니다.
  5. 생성된 /exec 주소를 복사해 위의 기록 저장하기에 넣습니다.

const HEADERS = ['이름', '시작일', '종료일', '플랫폼', '시간', '엔딩여부', '메모', '한줄평', 'Steam AppID', 'Steam 누적시간'];

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);

    if (data.action === 'createTemplate') {
      const sheet = getYearSheet(new Date().getFullYear());
      return output({ result: 'success' });
    }

    if (data.action === 'replaceAll') {
      const records = Array.isArray(data.records) ? data.records : [];
      replaceAllRecords(records);
      return output({ result: 'success', count: records.length });
    }

    const sheet = getYearSheet(getYear(data.startDate));
    sheet.appendRow(toRow(data));
    return output({ result: 'success' });
  } catch (error) {
    return output({ result: 'error', message: String(error) });
  }
}

function getYear(dateText) {
  const match = String(dateText || '').match(/^(\d{4})/);
  return match ? match[1] : String(new Date().getFullYear());
}

function getYearSheet(year) {
  const spreadsheet = SpreadsheetApp.getActiveSpreadsheet();
  const name = String(year);
  const sheet = spreadsheet.getSheetByName(name) || spreadsheet.insertSheet(name);
  if (sheet.getLastRow() === 0) sheet.getRange(1, 1, 1, HEADERS.length).setValues([HEADERS]);
  return sheet;
}

function toRow(data) {
  return [data.title || '', data.startDate || '', data.endDate || '', data.platform || '', Number(data.time || 0), data.isEnding || 'x', data.memo || '', data.review || '', data.steamAppId || '', data.steamTotal ?? ''];
}

function replaceAllRecords(records) {
  const spreadsheet = SpreadsheetApp.getActiveSpreadsheet();
  const groups = {};
  records.forEach(record => {
    const year = getYear(record.startDate);
    if (!groups[year]) groups[year] = [];
    groups[year].push(record);
  });
  spreadsheet.getSheets().forEach(sheet => {
    if (/^\d{4}$/.test(sheet.getName())) {
      sheet.clearContents();
      sheet.getRange(1, 1, 1, HEADERS.length).setValues([HEADERS]);
    }
  });
  Object.keys(groups).forEach(year => {
    const sheet = getYearSheet(year);
    const rows = groups[year].map(toRow);
    if (rows.length) sheet.getRange(2, 1, rows.length, HEADERS.length).setValues(rows);
  });
}

function doGet(e) {
  const p = e.parameter || {};
  if (p.action === 'gameRecords') return jsonp({ result: 'success', records: getAllRecords() }, p.callback);
  return jsonp({ error: '잘못된 요청입니다.' }, p.callback);
}

function getAllRecords() {
  const records = [];
  SpreadsheetApp.getActiveSpreadsheet().getSheets().forEach(sheet => {
    const values = sheet.getDataRange().getValues();
    if (values.length < 2) return;
    const headers = values[0].map(String);
    const column = name => headers.indexOf(name);
    const value = (row, name) => {
      const index = column(name);
      const item = index > -1 ? row[index] : '';
      return item instanceof Date ? Utilities.formatDate(item, Session.getScriptTimeZone(), 'yyyy-MM-dd') : item;
    };
    values.slice(1).forEach(row => records.push({
      title: value(row, '이름'), startDate: value(row, '시작일'), endDate: value(row, '종료일'),
      platform: value(row, '플랫폼'), time: value(row, '시간'), isEnding: value(row, '엔딩여부'),
      memo: value(row, '메모'), review: value(row, '한줄평'), steamAppId: value(row, 'Steam AppID'), steamTotal: value(row, 'Steam 누적시간')
    }));
  });
  return records;
}

function jsonp(data, callback) {
  const text = JSON.stringify(data);
  if (callback && /^[A-Za-z_$][0-9A-Za-z_$]*$/.test(callback)) {
    return ContentService.createTextOutput(callback + '(' + text + ')')
      .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }
  return output(data);
}

function output(data) {
  return ContentService.createTextOutput(JSON.stringify(data)).setMimeType(ContentService.MimeType.JSON);
}

Steam 연결 안내

이 화면에서는 SteamID64만 입력합니다. Steam API 키는 Vercel 환경 변수에만 보관되며 브라우저·구글 시트·GitHub에 입력하지 않습니다. 구글 시트는 Steam 동기화와 별개이며, 기록을 백업하거나 다른 브라우저에서 불러올 때만 필요합니다.

SteamID64 찾기

Steam 프로필 주소가 .../profiles/7656...라면, 뒤의 17자리 숫자가 SteamID64입니다. 주소가 /id/내이름처럼 보이면 SteamID 찾기에서 프로필 주소를 넣어 확인할 수 있습니다.

Steam 공개 설정

Steam 프로필 → 프로필 편집 → 개인정보 설정에서 게임 세부 정보를 공개로 바꿔야 게임 목록과 플레이 시간을 가져올 수 있습니다.

연결과 제목 정리

  • SteamID 저장: SteamID64만 이 브라우저에 저장합니다. API 키는 저장하지 않습니다.
  • Steam 기록 한꺼번에 연결: AppID가 비어 있는 기존 Steam 기록을 라이브러리와 비교합니다. 제목이 정확히 같거나 매우 비슷할 때만 자동 연결합니다.
  • Steam 상점 이름으로 제목 정리: 연결된 AppID를 기준으로 Steam 상점의 한국어 제목을 후보로 보여 줍니다. 체크한 항목만 바뀝니다.
  • Steam 최초 동기화 되돌리기: 특정 날짜에 한꺼번에 추가된 최초 Steam 동기화 기록만 골라 삭제합니다. 잘못된 대량 가져오기를 되돌릴 때 사용합니다.
  • 한국어 제목과 영어 API 이름이 다른 경우: 자동 연결이 안 되면 게임 상세의 Steam 게임 연결을 눌러 Steam 상점 주소를 한 번 붙여 넣으세요. AppID는 언어와 상관없이 같은 게임을 식별합니다.
  • 연결할 Steam 기록이 없습니다: 오류가 아닙니다. 이미 AppID가 연결됐거나 Steam 플랫폼 기록이 없다는 뜻입니다.

최근 플레이 동기화

총 플레이 시간이 0.3시간(18분) 이상인 게임만 가져옵니다. AppID가 연결된 기존 기록은 Steam 누적 시간과 비교하여 새로 늘어난 시간만 추가합니다. 시트에서 가져온 종료일보다 Steam 마지막 실행일이 더 최신이면, 해당 게임의 가장 최근 기록 종료일도 함께 갱신합니다. 첫 동기화는 Steam의 실제 마지막 실행일이 있는 게임만 기록하며, 날짜 정보가 없는 게임은 오늘 날짜로 임의 추가하지 않고 건너뜁니다.

🐹 Game Effect 사용법

1. 기본 사용법

  • 게임 기록하기: 게임 이름, 플레이 시간, 날짜 등을 입력하고 기록합니다.
  • 최근 플레이 동기화: SteamID64를 저장한 뒤 누르면 AppID별로 누적 시간을 비교해 늘어난 시간만 추가합니다. 시트의 종료일보다 Steam 마지막 실행일이 최신이면 종료일도 갱신합니다. 첫 기록 날짜는 마지막 실행일이며, 18분 미만 게임은 제외됩니다.
  • 달력 정보: Steam AppID가 연결된 게임에 마우스를 올리면 가능한 경우 썸네일·누적 플레이시간·업적 진행도를 봅니다. 정보를 가져올 수 없으면 해당 항목은 표시하지 않습니다.
  • 한줄평: 게임 전체에 대한 짧은 감상입니다.
  • 메모: 플레이한 날에 남기는 간단한 기록입니다.

2. 연동과 파일 저장

  • 연동 방법 안내 위치: 화면 위쪽의 구글 시트 연결하기 또는 Steam 연결하기를 펼칩니다. 구글 시트는 처음 설정하기, Steam은 Steam 연결 도움말에서 자세한 방법을 볼 수 있습니다.
  • 제목이 다른 Steam 기록: AppID가 같으면 같은 게임입니다. 한국어 상점명과 영어 API 이름이 다르면 게임 상세의 Steam 게임 연결에 상점 주소를 붙여 넣고, 필요할 때 Steam 상점 이름으로 제목 정리를 사용합니다.
  • 처음 데이터 통합 동기화: 시트 주소, Apps Script 저장 주소, SteamID64를 모두 설정한 뒤 사용합니다. 시트 → Steam AppID 연결 → Steam 최신 플레이 정보 순서로 처리하며, AppID를 확인하지 못한 기존 Steam 기록이 있으면 중복 생성을 막기 위해 멈춥니다.
  • 시트 동기화: 기록을 수정·삭제·제목 변환하면 현재 브라우저의 전체 기록이 연도별 시트에 반영됩니다. 첫 동기화 전에는 시트 기록을 먼저 불러오고, 중요한 시트는 사본을 만들어 두세요.
  • CSV로 저장: 가볍고 한 장짜리 파일입니다. 다른 서비스에 기록을 옮길 때 편합니다.
  • Excel로 저장: 시작일 연도별 탭이 나뉜 .xlsx 파일입니다. Excel에서 계속 정리할 때 편합니다.

3. 로컬 저장 확인

  • 기록을 추가한 뒤 새로고침해도 기록이 남아 있으면 정상 저장된 것입니다.
  • 저장된 기록은 현재 사용하는 이 브라우저에 보관됩니다. 다른 기기나 다른 브라우저에서는 자동으로 보이지 않습니다.
  • 다른 브라우저에서 불러오기: 구글 시트에 기록을 저장한 뒤, 다른 브라우저에서 같은 시트 주소를 넣고 기록 가져오기를 누르면 됩니다.
  • 데이터 초기화: 설정의 초기화는 이 브라우저의 게임 기록·편집 기록·Steam 제목 연결만 삭제합니다. 구글 시트, SteamID64, 시트 주소는 유지되며 시트 기록을 다시 가져올 수 있습니다.

4. 오류가 생겼을 때

  • Steam 게임 목록을 가져오지 못함: Steam의 게임 세부 정보를 공개로 바꾸고 SteamID64를 확인합니다. 사이트 관리자라면 Vercel의 STEAM_WEB_API_KEY가 Production 환경에 등록됐는지도 확인합니다.
  • 웹 앱 통신 중 오류: 구글 시트의 Apps Script에 최신 코드를 붙여 넣고 배포 관리 → 수정 → 새 버전으로 웹 앱을 다시 배포합니다. 실행 계정은 나, 액세스 권한은 모든 사용자이며, /exec 주소만 기록 저장하기에 넣습니다. /dev 주소는 사용할 수 없습니다.
  • 연결할 Steam 기록이 없습니다: 오류가 아니라 이미 가져왔거나 새 플레이 기록이 없는 상태일 수 있습니다.
  • 새로 늘어난 시간이 없음: 플레이 시간이 늘지 않았거나 늘어난 시간이 0.3시간보다 짧습니다.

화면 모드

최근 편집 기록

아직 편집 기록이 없습니다.

되돌리기: 선택한 편집 직전의 전체 기록 상태로 돌아갑니다. 그 편집 이후에 한 추가·수정·삭제도 함께 사라질 수 있으니, 가장 최근 기록부터 되돌리는 것을 권장합니다. 최근 5개까지만 저장됩니다.

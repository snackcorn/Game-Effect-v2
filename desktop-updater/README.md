# Game Effect 로컬 데이터 업데이트

`Start.cmd`를 더블클릭합니다. 브라우저와 Excel 설치 없이 실행하는 윈도우 창입니다. Python 3.10 이상과 Tcl/Tk가 필요하며, 추가 패키지 설치는 없습니다. 현재 PC의 Python으로 실행할 수 있습니다.

## 사용하는 순서

1. 지금 연결된 구글 시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)**로 내려받습니다.
2. `Start.cmd`를 열고 **파일 선택**으로 내려받은 파일을 선택합니다. 파일을 `Start.cmd` 위에 끌어 놓아도 됩니다.
3. 대상 사이트 버전, **변경 예정**, **확인 사항**을 확인합니다.
4. **원본 백업 + 변환 사본 저장**을 누릅니다. 원본 파일은 수정하지 않습니다.
5. 결과 폴더의 **먼저읽기.txt**를 확인한 후 변환 사본을 사용합니다. 확인 사항이 있다면 해결한 뒤 다시 검사합니다.

기본 결과 위치는 사이트 폴더 안 `.local-only/data-updates/날짜-고유번호/`입니다. 매번 새 폴더에 원본 백업, 변환 사본, 변경 보고서(JSON/TXT)를 함께 저장합니다. 이 파일들은 개인 데이터이므로 GitHub에 업로드하지 마세요. GitHub 웹 업로드는 `.gitignore`를 적용하지 않습니다.

도구는 구글 계정·사이트·시트에 접속하지 않습니다. 변환 사본을 구글 시트에서 연 뒤 연도별 원본 탭에 반영하고 사이트에서 시트 불러오기를 해야 적용됩니다. 원래 시트 주소를 유지하려면 파일을 새 시트로 연 뒤 변경한 원본 탭만 기존 시트에 반영하세요. **게임 정리**와 변경 기록 같은 보조 탭은 이 도구에서 수정하지 않습니다. 게임 정리 탭은 사이트의 시트 동기화 때 갱신됩니다.

## 현재 규칙 — 사이트 v2.74

- 연도별 원본 탭을 현재 16개 표준 열 구조로 맞춥니다. 기존 추가 열과 보조 탭은 보존합니다.
- 비어 있는 기록 ID만 생성합니다. 같은 입력을 다시 처리해도 같은 ID가 나옵니다.
- `시간`을 기준으로 호환용 `플레이시간(분)`만 맞춥니다. 시간·날짜·게임 이름·한줄평·기존 ID는 변경하지 않습니다.
- 런처 부모가 있으면 런처 배분 표시를 보완합니다. 부모·하위 게임의 ID를 추측하거나 바꾸지 않습니다.
- 누락 날짜·잘못된 시간·중복 ID·중복 내용·불완전한 런처 연결은 확인 목록에 남깁니다. 행 삭제·합산·누적/증가량 재해석은 하지 않습니다.
- 이미 현재 형식이면 **변환할 내용 없음**으로 표시합니다. 다시 넣어도 추가 변환이 발생하지 않습니다.

현재 내보내기 파일에는 원본 사이트 버전이 없으므로, 출처 버전을 임의로 판정하지 않습니다. 실제 열·값을 검사하고 등록된 규칙만 적용합니다. 결과 보고서에 대상 사이트 버전, 데이터 형식 버전, 적용 규칙과 입력·출력 해시를 기록합니다.

지원: `.xlsx`, UTF-8/CP949 `.csv`, 기록 객체 배열 또는 `records`/`events` 배열 JSON. JSON은 개발·백업 데이터용이며 사이트에 JSON 파일 직접 가져오기 기능을 추가하는 것은 아닙니다. `.xls`, 암호화·서명된 문서, 보호된 기록 시트는 지원하지 않습니다. 수식이 있는 기록 행, 수식·차트 참조에 영향을 주는 열 이동, 표·병합 셀의 구조 변경은 원본 보호를 위해 중단합니다. 엑셀 구조와 수식은 재계산하지 않습니다.

## 사이트 업데이트와 함께 관리하기

사이트 버전이 바뀔 때 도구도 같은 변경에 포함합니다.

1. `release.json`의 `targetSiteVersion`을 사이트 버전과 맞춥니다. 도구 변경 시 `toolVersion`을 올립니다.
2. 데이터 변경이 없으면 기존 규칙을 유지합니다. 표현·성능·보안 업데이트를 이유로 기록 값을 바꾸지 않습니다.
3. 데이터 구조 변경이 있으면 `migrator.py`에 새 이름의 변환 함수를 등록하고 `migrations` 목록 뒤에 추가합니다. 형식이 바뀌면 `schemaRevision`과 표준 열도 갱신합니다.
4. 기존 규칙을 지우거나 다른 의미로 바꾸지 않습니다. 새 규칙은 반복 적용해도 같은 결과가 나와야 합니다.
5. 아래 검증을 실행하고 사이트 파일과 도구 폴더를 함께 배포합니다. 이 도구 폴더는 `.vercelignore`로 웹 배포에서 제외됩니다. 사용자는 사이트 버전에 맞는 도구 폴더 전체를 교체합니다.

```powershell
python desktop-updater/app.py --check-release
python -m unittest discover -s desktop-updater/tests -v
```

명령행 검사·변환도 지원합니다. 저장 없이 검사하려면 `--inspect`를 사용합니다.

```powershell
python desktop-updater/app.py --inspect "연동용 데이터.xlsx"
python desktop-updater/app.py --convert "연동용 데이터.xlsx" --output-dir ".local-only/data-updates"
```
